# 0058 — Scoate Pre-Intro tab din header pentru admin

## Context

Utilizatorii cu rol ADMIN văd în header toate opțiunile de navigare (superuser), inclusiv tab-ul "Pre-Intro" care duce la `/preintroducer`. Cerința: **scoate tab-ul Pre-Intro din header pentru admin** — adică admin nu mai vede linkul "Pre-Intro" în bara de navigare.

## Fișiere de modificat

- **`frontend/src/components/layout/Header.tsx`**  
  În `useMemo` care construiește `navLinks`, în ramura `if (isAdmin)` (linii 71–78), se adaugă în prezent linkul `{ href: '/preintroducer', label: 'Pre-Intro', icon: null }`. Trebuie **eliminat** acest push; restul linkurilor pentru admin (Dashboard, Funding, CEA Cash, Swap, Onboarding, Introducer) rămân neschimbate.

## Comportament dorit

- **Admin**: header-ul afișează Dashboard, Funding, CEA Cash, Swap, Onboarding, Introducer — **fără** Pre-Intro.
- **PREINTRODUCER**: continuă să vadă un singur link relevant (Referral Code către `/preintroducer`) — logică existentă, neschimbată.
- **Alte roluri**: neschimbate.

## Detalii tehnice

- Linkul Pre-Intro pentru admin este definit la linia 78:  
  `links.push({ href: '/preintroducer', label: 'Pre-Intro', icon: null });`
- Eliminarea acestei linii este suficientă; nu sunt necesare schimbări de rute, permisiuni backend sau alte fișiere.
- Desktop și mobile folosesc același `navLinks`, deci Pre-Intro dispare pentru admin în ambele view-uri.
