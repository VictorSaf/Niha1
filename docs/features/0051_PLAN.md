# Feature 0051: Ascundere Pre-Intro din header pentru rol Admin

## Summary

Pentru utilizatorii cu rol **admin**, linkul de navigare "Pre-Intro" (href `/preintroducer`) trebuie scos din header-ul aplicației. Adminii nu trebuie să vadă acest link în bara de navigare.

**Detalii verbatim din cerere**:

- **Rol**: admin
- **Acțiune**: scoate Pre-Intro din dashboard (header nav)
- **DOM Path**: `div#root > … > header > … > nav > a[href="/preintroducer"]`
- **Element**: `<a class="text-sm font-medium …" href="/preintroducer">Pre-Intro</a>`
- **Poziție**: top=30px, left=1208px, width=59px, height=20px
- **React component**: LinkWithRef (Link din react-router-dom)

## Context

- `app_truth.md`: User role is SSOT; rolurile includ ADMIN, PREINTRODUCER, TRODUCER, INTRODUCER, etc.
- Header-ul construiește `navLinks` în funcție de `role`; pentru `isAdmin` (role === 'ADMIN') se afișează toate opțiunile, inclusiv Pre-Intro. Cererea este să nu se mai afișeze Pre-Intro pentru admin.

## Fișiere și acțiuni

| Fișier | Acțiune |
|--------|---------|
| `frontend/src/components/layout/Header.tsx` | La construirea `navLinks` pentru `isAdmin`, nu mai adăuga linkul `{ href: '/preintroducer', label: 'Pre-Intro', icon: null }`. Restul linkurilor (Dashboard, Funding, CEA Cash, Swap, Documents, Onboarding, Introducer) rămân neschimbate. |

## Algoritm

1. În `useMemo` care construiește `navLinks` (după linia 72), în ramura `if (isAdmin)`:
   - Păstrezi push-urile pentru Dashboard, Funding, CEA Cash, Swap, Documents, Onboarding, Introducer.
   - **Elimini** linia care face `links.push({ href: '/preintroducer', label: 'Pre-Intro', icon: null });`.

2. Nicio modificare la rute (`App.tsx`), la CommandPalette sau la alte roluri (PREINTRODUCER continuă să vadă "Referral Code" către `/preintroducer`).

## Consistență

- Stil și convenții: niciun nou pattern; doar eliminare unui element din array-ul de linkuri.
- Role logic rămâne în `getEffectiveRole(user, simulatedRole)` și `role === 'ADMIN'`; nu se schimbă definiția de admin.
